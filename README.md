📱 Mobile Sales and Revenue Analysis Dashboard

📌 Project Overview

The Mobile Sales and Revenue Analysis Dashboard is a data analytics project developed using Microsoft Power BI. This project analyzes mobile sales data to understand revenue performance, product performance, state-wise sales, and monthly sales trends.

The dashboard transforms raw data into interactive visualizations that help users explore business performance and make data-driven decisions.

🎯 Project Objectives

* Analyze total mobile sales and revenue.
* Track the total quantity of mobile phones sold.
* Identify top-performing states and products.
* Analyze sales performance across different product categories.
* Understand monthly sales trends.
* Develop an interactive dashboard for business reporting.
* Support data-driven decision-making.

🛠️ Tools and Technologies

* **Microsoft Power BI:** Dashboard development and data visualization.
* **Microsoft Excel:** Data storage and preparation.
* **Power Query:** Data cleaning and transformation.
* **DAX:** Creating measures and performing calculations.

📊 Key Performance Indicators (KPIs)

The dashboard provides an overview of sales performance through important metrics:

* **Total Quantity Sold:** Total number of mobile units sold.
* **Total Revenue:** Revenue generated from mobile sales.
* **Sales Performance:** Overview of sales across products and regions.

📈 Dashboard Features

1. State-wise Sales Analysis

Analyze sales performance across different states and compare regional results.

2. Top 5 States by Sales

Identify the five highest-performing states based on the selected sales metric.

3. Top 10 Products Analysis

Analyze product performance and identify the top 10 products based on sales.

4. Category-wise Sales Analysis

Compare sales across different product categories.

5. Monthly Sales Trend

Visualize monthly sales performance and identify changes over time.

6. Interactive Slicers and Filters

Filter dashboard results using available dates, states, products, and other fields.

7. KPI Cards

Display key business metrics in a clear and visually appealing format.

🧮 DAX Measures

DAX (Data Analysis Expressions) is used to create calculations in Power BI.

Total Revenue

```DAX
Total Revenue = SUM('Mobile Sales'[Revenue])
```

Total Quantity Sold

```DAX
Total Quantity Sold = SUM('Mobile Sales'[Quantity])
```

*Note: These examples assume your table is named `Mobile Sales` and contains the specified columns. Update the names to match your actual dataset.*
